# 시현가챠 💖

레버를 돌려 김시현을 하나씩 뽑아보는 자기소개 뽑기 머신

## 사용 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다.
2. 레버를 눌러 캡슐을 뽑습니다.
3. 캡슐 내용을 확인한 뒤 **컬렉션에 넣기**를 누릅니다.
4. 모은 캡슐은 아래 컬렉션에서 다시 확인할 수 있습니다.
5. 컬렉션을 모두 모으면 **처음부터 다시 뽑기**로 다시 시작할 수 있습니다.

## 히든 캡슐 힌트

시현가챠에는 특별한 히든 캡슐이 숨어 있어요. 하나씩 뽑아 컬렉션을 완성해 보세요!
